## 第五阶段执行链

课程或多书任务的主链为：

```text
Planner Agent
  -> 解析当前问题并生成两个模板之一
  -> 校验任务类型、约束、步骤、工具白名单和调用上限
Executor Agent
  -> 再次校验计划并在私有副本上执行
  -> 顺序调用 MCP，将原始 ToolEnvelope 深拷贝保留在内存
Reviewer Agent
  -> 核对计划、轨迹和原始证据
  -> 独立重算课程筛选或二手书最低组合
  -> 通过后发布；拒绝或异常则 review_failed
```

可执行任务的事件顺序为：

```text
start
 -> agent_start(planner) -> agent_result(planner) -> plan
 -> agent_start(executor) -> steps/tools -> agent_result(executor)
 -> agent_start(reviewer) -> agent_result(reviewer)
 -> task_result -> delta -> done
```

原始工具 `items` 不发送给网页。Reviewer 结束前没有 `task_result` 或答案 `delta`，因此未经复核的候选推荐不会作为最终回答进入浏览器或会话。工具失败可以被 Reviewer 认定为“如实失败且无推荐项”，但任务状态仍为 `failed`，不会变成成功。

## 使用与边界

启动：`python -m campus_agent serve`，浏览器打开 `http://127.0.0.1:8000`。必须使用安装了依赖的同一 Python 解释器；本机真实知识检索／自然语言生成还需 Ollama 运行。

可试：

```text
请用多 Agent 为 DEMO001 推荐一门周二下午评分高、不点名的通识课
请让 Planner、Executor 和 Reviewer 为 DEMO002 推荐周二下午不冲突的通识课
用多 Agent 比较《高数》和《线代》二手书，总预算50元
帮我买高数、线代、概统各一本，总预算80元
```

未指定演示学生时会声明使用 `DEMO001`，不是用户本人课表。课程推荐是独立备选；“周二下午没课”解释为找该时段可上且不冲突的课，并不宣称整段下午空闲。模拟结果不代表真实开课、库存或交易；书名近名检索可能命中辅导书，必须核验实际教材版本。系统没有下单、联系卖家或改变选课的能力。
