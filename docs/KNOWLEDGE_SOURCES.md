# 知识库来源清单模板

公开仓库不附带本地知识源、派生文本缓存或生成索引。本文件用于项目部署方在本地记录已经授权、审核并导入的资料，不应填写密码、Cookie、Token、个人账号或不必要的本机绝对路径。

## 资料清单

| 相对文件名 | 来源单位与公开链接 | 权威级别 | 核验状态 | 适用范围 | 核验日期 | 时效等级 |
| --- | --- | --- | --- | --- | --- | --- |
| `示例通知.md` | `主管部门 / https://example.scut.edu.cn/notice` | `official` | `verified` | `全校` | `YYYY-MM-DD` | `high` |

实际属性应保存在每份资料旁的同名 `.meta.json` 中；字段格式见 `KNOWLEDGE_INGESTION.md`。如需完整性审计，可以在仅限授权人员访问的本地记录中保存 SHA-256，但不要把内部路径、私有文件哈希或未获再分发许可的资料提交到公开仓库。

## 导入与验收记录

每次发布前至少记录：

- 资料数量、解析成功／失败数量和警告；
- 解析器版本、嵌入模型名称、向量维度和片段数量；
- 语料是否经过来源、适用范围、发布日期及时效复核；
- 代表性正向检索、知识缺口和过期内容的反向测试；
- OCR 或人工转录缓存的生成方式与复核人，但不在公开记录中填写个人敏感信息。

示例命令：

```powershell
python -m campus_agent ingest --force
python -m campus_agent search "测试问题"
python -m unittest discover -s tests -v
```

`source-provided` 只表示本地文件已收到并可解析，不等同于官网核验；`pending-review` 内容不得作为确定性校规结论。网页端只展示回答正文，因此来源、告警和审核结果必须通过本地治理记录与终端检索留存。
